# Niigata Data Archive

新潟的数据资料与早期统计可视化档案。2026-11-02 从 `niigata-data-viz` 改名为 `niigata-data-archive`，本仓库随后设为只读归档；保留历史，不在这里继续制作动画。

## 新潟小动画已迁出

四季旅行小动画现独立为 **[Niigata Mini Animations](https://github.com/gitcyx93/niigata-mini-animations)**，后续动画制作请到新仓库。

新仓库包含高田夜樱、长冈花火、弥彦、越后汤泽等动画页面，共用代码、制作工具、相关调研、MP4、发布文案和原提交历史。各季作品入口与版本说明见新仓库 README。

原动画工作分支保留为历史快照，不删除、不强推；新仓库的 `archive/source/*` 另有对应提交的归档标签（原迁移快照分支已转为同名标签）。迁移范围与固定提交映射见 [迁移记录](https://github.com/gitcyx93/niigata-mini-animations/blob/main/docs/MIGRATION.md)。

## 本仓库保留

- [`data/`](data/)：数据、来源与核验备忘。
- [`reference/niigata-cinema-zh.html`](reference/niigata-cinema-zh.html)：早期统计交互页面（含住宿、四季分布、佐渡、口碑），**不是四季旅行动画工程**。
- [`dashboard/`](dashboard/) 与 [`scripts/`](scripts/)：旧统计看板和生成脚本，仅供参考。

GitHub 文件页显示 HTML 源码；查看统计交互页需下载后在浏览器打开。
